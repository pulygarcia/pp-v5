Plataforma web fullstack completa de eventos, gestión y estadísticas de artes marciales.

Diseñada para simular la plataforma real de una organización deportiva, con control a nivel administrador y gestión de datos escalable.

## Funcionalidades

- **Autenticación y roles** — Login y registro con acceso basado en roles (Usuario, Admin).
- **Panel de administración** — Panel administrativo completo para gestionar eventos, carteleras, peleadores, resultados y rankings.
- **Gestión de eventos** — Visualización de eventos próximos y pasados con información detallada de cada uno.
- **Carteleras y evento principal** — Carteleras completas con el evento principal destacado.
- **Perfiles de peleadores** — Perfiles detallados con estadísticas físicas, categoría de peso e historial de combates.
- **Resultados y estadísticas** — En eventos pasados, los usuarios acceden a resultados y estadísticas como golpes conectados, knockdowns y más.
- **Integración con API externa** — Noticias en tiempo real consumidas desde APIs de terceros.
- **Integridad y validación de datos** — Gestión controlada de datos para garantizar consistencia entre eventos, peleadores y resultados.
